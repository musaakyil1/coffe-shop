## Documentation

This site is a static Coffee Shop website. The public surface consists of HTML sections, CSS utilities/variables, and a minimal JavaScript behavior for the responsive navbar.

- See `api.md` for JavaScript API and usage examples.
- See `components.md` for HTML structure and component usage.
- See `styles.md` for CSS variables, utilities, and responsive behavior.

### Quickstart

1. Open `index.html` in a browser.
2. Resize the viewport to see the responsive navbar. Click the menu icon to toggle the mobile navigation.

### File Overview

- `index.html`: Page markup and sections.
- `style.css`: Global styles, CSS variables, components, and responsive rules.
- `main.js`: Small script to toggle the navbar on mobile.
