# Coffee Shop Website Documentation

This site is a static, responsive coffee shop landing page built with HTML, CSS, and a small JavaScript interaction for the mobile menu.

## Contents

- Getting Started: `getting-started.md`
- Components: `components.md`
- JavaScript API: `javascript-api.md`
- CSS Tokens & Utilities: `css.md`
- Examples: `examples.md`

## Overview

- Single-page design with sections: header, home, about, menu, products, reviews, contact-us, blogs, footer.
- Responsive layout via media queries at 800px and 600px.
- Mobile navigation menu toggled by the "hamburger" icon.
