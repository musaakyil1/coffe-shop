## Getting Started

### Requirements
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools are required

### Run Locally
Open `index.html` in your browser, or serve the project root via any static server:

```bash
python3 -m http.server 8080
# visit http://localhost:8080
```

### Project Files
- `index.html`: Main page markup
- `style.css`: Global styles, variables, responsive rules
- `main.js`: Navbar toggle behavior for mobile
- `images/`: Image assets used across sections

### Conventions
- Class-based styling; components are identified by section and utility classes (e.g. `btn`, `heading`)
- Responsive behavior controlled with media queries (800px and 600px breakpoints)
