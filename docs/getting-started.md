# Getting Started

## Prerequisites

- Any modern web browser
- (Optional) A lightweight static server or IDE extension such as Live Server

## Run Locally

1. Open `index.html` directly in your browser, or serve the folder with a static server.
2. Ensure `style.css` and `main.js` are in the same directory as `index.html`.
3. On small screens, tap the menu icon to open the mobile navigation.

## Project Structure

```
index.html       # Markup and section structure
style.css        # Styling, responsive rules, CSS variables
main.js          # Mobile menu toggle interaction
images/          # Images used across sections
docs/            # This documentation
```
